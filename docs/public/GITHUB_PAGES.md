# GitHub Pages

O REST Gentill possui uma landing page pública de portfólio pronta em `docs/`.

## Ativação

No GitHub:

1. abra **Settings**;
2. acesse **Pages**;
3. em **Build and deployment**, escolha **Deploy from a branch**;
4. selecione a branch `main`;
5. selecione a pasta `/docs`;
6. salve.

Após a publicação, o endereço esperado é:

```text
https://viniciusvilaverd-22.github.io/GENTILL-RAST/
```

## Conteúdo

A página publica apenas material documental de portfólio:

- visão do produto;
- arquitetura;
- engineering highlights;
- stack;
- papel no projeto;
- links para documentação pública.

Nenhum código-fonte do produto, segredo, dump ou evidência interna é publicado pela página.
