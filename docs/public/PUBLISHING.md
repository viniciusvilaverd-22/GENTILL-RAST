# Modelo de Publicação

Este repositório público foi preparado como uma publicação **somente documental** do REST Gentill.

## Conteúdo público

A publicação inclui:

- visão geral do produto;
- arquitetura;
- descrição dos componentes;
- modelo de segurança;
- visão de implantação;
- políticas de segurança e contribuição.

## Conteúdo não incluído

Permanecem privados:

- código-fonte;
- binários e instaladores;
- agentes compilados;
- dumps e backups;
- dados de homologação;
- credenciais e chaves;
- histórico operacional interno;
- evidências técnicas locais.

## Histórico

A publicação documental utiliza histórico Git independente da árvore de desenvolvimento.

Essa separação evita que arquivos removidos ou materiais internos de desenvolvimento fiquem acessíveis por commits antigos.

## Distribuição

O repositório documental pode ser disponibilizado publicamente sem expor o código-fonte do produto.

A documentação permanece sujeita aos termos definidos em `LICENSE`.
