THE PROBLEM

Identity, assets and position are not the same thing.

The project starts with a simple question: how do you keep consistency when an asset has an endpoint, an agent installation, a responsible person, a reference location and a dynamic position — each with a different lifecycle?

Asset ≠ Device ≠ Agent Installation ≠ Last Position

ARCHITECTURE

Explicit authorities. Clear responsibilities.

ENGINEERING HIGHLIGHTS

From product model to runtime.

Identity & Security

OIDC/RBAC for humans, individual agent credentials, DPAPI on Windows, secure Android storage and file-based secrets.

Telemetry

REST Core owns the business domain; Traccar owns location; PostGIS provides geospatial context.

Multi-platform

Web dashboard, field PWA, native Windows agent, native Android agent and Linux control plane.

Offline-first

Android considers connectivity loss, local queueing and later synchronization as part of the operational model.

Recoverability

Backup, restore and rollback are explicit architectural capabilities.

Governance

Migrations, versioned contracts, baselines and candidates reduce regression across clients and services.
